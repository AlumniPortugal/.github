# Security Policy

## Supported versions

Alumni Portugal projects are maintained by volunteers. Unless a repository
documents a different policy, only the latest version on its default branch is
supported with security updates.

## Report a vulnerability

Do not report suspected vulnerabilities in a public issue, pull request, or
Discussion.

1. Open the affected repository's **Security** tab.
2. Use **Report a vulnerability** when private vulnerability reporting is
   available.
3. If it is unavailable, contact an Alumni Portugal organization owner through
   an established private channel and request a secure reporting channel.

Include the affected repository and version, impact, reproduction steps, and
any suggested mitigation. Avoid accessing, modifying, or retaining data that
does not belong to you.

Maintainers will acknowledge a report when it is received, investigate it, and
coordinate remediation and disclosure with the reporter. Response times depend
on volunteer availability and the severity of the issue.
