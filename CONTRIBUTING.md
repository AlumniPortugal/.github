# Contributing to Alumni Portugal

Thank you for helping the 42 Portugal alumni community. Contributions of all
sizes are welcome, including documentation, bug reports, design proposals,
code, and alumni directory updates.

## Before you start

- Read the target repository's README and local contribution instructions.
- Search existing issues and pull requests before opening a duplicate.
- Use GitHub Discussions for questions and early-stage ideas that are not yet
  actionable.
- Use an issue for a reproducible bug or a clearly scoped feature.
- Never include credentials, private alumni data, or security vulnerabilities
  in a public issue or pull request.

Repository-specific instructions take precedence over these organization-wide
defaults.

## Make a contribution

1. Fork or clone the relevant repository.
2. Create a focused branch from its default branch.
3. Make one coherent change and add or update tests when appropriate.
4. Run the repository's documented validation and build commands.
5. Commit with a concise description of the change.
6. Open a pull request and complete its checklist.
7. Address automated checks and reviewer feedback.

Keep pull requests small enough to review. Explain what changed, why it is
needed, and how reviewers can verify it. Link related issues with `Closes #123`
when the pull request resolves them.

## Alumni directory entries

Directory submissions belong in
[`AlumniPortugal.github.io`](https://github.com/AlumniPortugal/AlumniPortugal.github.io).
Follow that repository's README and add or update only your own profile unless
you are an authorized maintainer.

## Reviews and conduct

Approval may be required from repository code owners. A maintainer may request
changes or close contributions that are unsafe, out of scope, unverifiable, or
inconsistent with the community's goals.

Participation is subject to our [Code of Conduct](CODE_OF_CONDUCT.md).
