# 42 Alumni Portugal

Community-run home of the 42 Lisboa and 42 Porto alumni network — built and maintained by
alumni, for alumni. Not affiliated with 42.

**[alumniportugal.github.io](https://alumniportugal.github.io/)** · [Join the directory](https://github.com/AlumniPortugal/AlumniPortugal.github.io/blob/main/.github/PULL_REQUEST_TEMPLATE/new-entry.md) · [Post a job or referral](https://github.com/AlumniPortugal/AlumniPortugal.github.io/issues/new?template=job.yml)

## What we run

| | What it is | Where |
|---|---|---|
| **Alumni Directory** | A voluntary directory of who is doing what — field, company, skills, and whether you're open to mentoring, collaborating, or hiring. | [alumniportugal.github.io/directory](https://alumniportugal.github.io/directory/) |
| **Jobs & Referrals** | Open roles posted by alumni, with referrals, reviewed by the community board before they go live. | [alumniportugal.github.io/jobs](https://alumniportugal.github.io/jobs/) |
| **Certification Calculator** | Maps your 42 projects to certifications worth taking. | [cert-calculator](https://github.com/AlumniPortugal/cert-calculator) |

## Take part

- **Add yourself to the directory.** One YAML file, one pull request, CI validates it. Start with
  the [entry guide](https://github.com/AlumniPortugal/AlumniPortugal.github.io/blob/main/.github/PULL_REQUEST_TEMPLATE/new-entry.md).
- **Post a role.** Use the [job issue form](https://github.com/AlumniPortugal/AlumniPortugal.github.io/issues/new?template=job.yml);
  it appears on the site once a board member approves it.
- **Fix something.** The site is a static Next.js export on bun — see the
  [contribution guide](https://github.com/AlumniPortugal/AlumniPortugal.github.io/blob/main/README.md#develop).

## Principles

- **Voluntary and public.** Directory data is what alumni choose to publish; nothing private or inferred.
- **Peer-first.** Referrals come from alumni, not from scraped job boards.
- **Small surface.** Static hosting, Git as the database, no accounts and no tracking.
