# Support

Choose the channel that best matches your request:

- **Setup and usage:** read the relevant repository's README first.
- **Questions and community help:** use
  [Alumni Portugal Discussions](https://github.com/orgs/AlumniPortugal/discussions).
- **Reproducible bugs:** open a bug report in the affected repository.
- **Feature proposals:** open a feature request in the affected repository.
- **Alumni directory updates:** follow the instructions in
  [`AlumniPortugal.github.io`](https://github.com/AlumniPortugal/AlumniPortugal.github.io).
- **Security vulnerabilities:** follow the private process in our
  [Security Policy](SECURITY.md); never publish vulnerability details in an
  issue.

This is a volunteer-run community. Please provide enough context for someone
else to reproduce or understand the request and allow reasonable time for a
response.
